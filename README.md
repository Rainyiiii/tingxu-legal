# TingXu public website

This folder contains deployable static pages for the App Store support and privacy-policy URLs.

- `index.html` — product overview
- `privacy.html` — full bilingual privacy policy
- `support.html` — bilingual support/FAQ
- `styles.css` — shared styling
- `assets/` — original app icon and staging screenshots

Deployed at:

- Landing: https://rainyiiii.github.io/tingxu-legal/
- Privacy: https://rainyiiii.github.io/tingxu-legal/privacy.html
- Support: https://rainyiiii.github.io/tingxu-legal/support.html

These pages are deployed from the dedicated public repository `Rainyiiii/tingxu-legal` at its root. The URLs above are used in App Store documentation and in-app links.

The site contains no tracking scripts, cookies, remote fonts, analytics or third-party embeds. It is suitable for a static host with no backend.

The screenshots are DEBUG staging images for visual review; do not present them as real user health data.
